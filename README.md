# Learning TypeScript

This repository documents my journey learning TypeScript from the ground up. 
As a MERN stack developer, I'm strengthening my skills with static typing 
to write safer, more maintainable code.

## What's Inside
- 💻 Hands-on exercises for each topic
- 🚀 Mini-projects applying TypeScript in real scenarios

## Topics Covered
- Basic types, interfaces, and type aliases
- Functions, generics, and utility types
- Classes and OOP in TypeScript
- Working with the DOM and third-party libraries

## Goal
To build a solid, practical understanding of TypeScript that I can apply 
confidently in real-world full-stack projects.
